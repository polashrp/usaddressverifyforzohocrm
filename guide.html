📊 Executive Summary

US Address Verify for Zoho CRM automatically validates and verifies US addresses in your Leads, Contacts, and Accounts modules.

✅ Improve Data Quality

Ensure all addresses are accurate and deliverable

✅ Reduce Failed Deliveries

Catch invalid addresses before they cause problems

✅ Save Time

Automate address verification instead of manual checking

✅ Gain Insights

Get county, coordinates, and time zone data for every address

🚀 Key Features

1. Smart Address Verification

StatusDescription
ValidAddress is verified and deliverable
InvalidAddress could not be verified
Outside USAddress is outside the United States
MissingAddress information is incomplete
Not CheckedAddress has not been verified yet

2. Enriched Address Data

  • County – County name where the address is located
  • County FIPS – Unique 5-digit code for the county
  • State FIPS – 2-digit code for the state
  • Latitude – Geographic latitude coordinate
  • Longitude – Geographic longitude coordinate
  • Time Zone – Time zone of the location
  • Verified Address – Standardized, postal-approved address

📥 Installation Guide

Step 1: Install the Extension

  1. Go to Zoho Marketplace
  2. Search for "US Address Verify"
  3. Click Install
  4. Follow the installation wizard
  5. Grant necessary permissions

Step 2: Set Up Workflow Rules

ModuleWorkflow NameTrigger
LeadsAuto Verify Lead AddressOn Create / On Edit
ContactsAuto Verify Contact AddressOn Create / On Edit
AccountsAuto Verify Account AddressesOn Create / On Edit

Step 3: Add Related Lists

  1. Go to Setup > Customization > Modules and Fields
  2. Select each module (Leads, Contacts, Accounts)
  3. Click Layouts tab
  4. Add the Address Validation Related List

Step 4: Add Custom Buttons

❓ FAQs

Does this work with non-US addresses?

No, this extension is specifically designed for US addresses only.

Do I need to configure field mapping?

No, the extension automatically detects your CRM's address fields.

Can I verify addresses manually?

Yes, use the "Verify Address" button on any record.

Can I verify both Billing and Shipping addresses?

Yes, for Accounts, both Billing and Shipping addresses are verified separately.

How do I run reports?

Weekly and Monthly reports run automatically on schedule. You can also run a Selected Report from the list view.
